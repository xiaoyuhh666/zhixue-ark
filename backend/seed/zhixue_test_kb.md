# 数据结构期末复习资料（测试知识库）

## 复习总体策略

数据结构期末考试重点集中在：线性表、栈与队列、树与二叉树、图、查找、排序六大模块。
建议采用「三遍复习法」：第一遍过概念与性质，第二遍手写核心算法，第三遍刷历年真题并整理错题本。

## 线性表

- 顺序表：随机访问 O(1)，插入删除平均移动一半元素 O(n)。
- 单链表：插入删除只需修改指针 O(1)（已定位前提下），但查找只能顺序遍历 O(n)。
- 考点：头插法建表结果逆序，尾插法保持原序；带头结点的链表在插入删除时无需特判第一个位置。

## 栈与队列

- 栈：后进先出 LIFO。入栈出栈序列问题：n 个元素入栈，合法出栈序列数为卡特兰数 C(2n,n)/(n+1)。
- 队列：先进先出 FIFO。循环队列判满：(rear+1) % maxSize == front；队中元素个数 (rear-front+maxSize) % maxSize。
- 应用：栈用于括号匹配、表达式求值、递归转非递归；队列用于层次遍历、缓冲区、BFS。

## 树与二叉树

- 性质：二叉树第 i 层最多 2^(i-1) 个结点；深度为 k 的二叉树最多 2^k - 1 个结点；n0 = n2 + 1。
- 遍历还原：先序 + 中序、后序 + 中序可唯一确定二叉树；先序 + 后序不能。
- 二叉排序树 BST：中序遍历得到递增序列；删除结点分三种情况（叶子/单孩子/双孩子用中序前驱或后继替换）。
- 平衡二叉树 AVL：任一结点左右子树高度差不超过 1；插入后通过 LL/RR/LR/RL 四种旋转恢复平衡。
- 哈夫曼树：带权路径长度 WPL 最小的二叉树；哈夫曼编码是前缀码，左分支为 0 右分支为 1。

## 图

- 存储结构：邻接矩阵适合稠密图，邻接表适合稀疏图。
- 遍历：深度优先 DFS 用栈（或递归），广度优先 BFS 用队列，两者对邻接表都是 O(n+e)。
- 最小生成树：Prim 适合稠密图 O(n²)，Kruskal 适合稀疏图 O(eloge)。
- 最短路径：Dijkstra 单源最短路，不能处理负权边；Floyd 求任意两点间最短路，三重循环 O(n³)。
- 拓扑排序：只能用于有向无环图 DAG；AOV 网顶点排序，AOE 网关键路径决定工程最短工期。

## 查找

- 折半查找：要求有序顺序表，平均查找长度约 log2(n)，最多比较 ⌈log2(n+1)⌉ 次。
- 散列表：冲突处理开放定址法（线性探测易堆积）与链地址法；装填因子 α = 表中记录数 / 表长，ASL 与 α 有关。

## 排序

- 插入排序：直接插入 O(n²) 稳定；希尔排序 O(n^1.3) 不稳定。
- 交换排序：冒泡 O(n²) 稳定；快排平均 O(nlogn) 最坏 O(n²) 不稳定，是内部排序中平均性能最优者。
- 选择排序：简单选择 O(n²) 不稳定；堆排序 O(nlogn) 不稳定，适合大文件Top-K问题。
- 归并排序：O(nlogn) 稳定，需要 O(n) 辅助空间。
- 基数排序：O(d(n+r)) 稳定，d 为位数 r 为基数，不基于比较。
- 高频考点：各排序算法一趟结果判断、稳定性辨析、堆的建立与调整。

## 两周冲刺计划

- 第 1 周：线性表、栈队列、树与二叉树，每天 2 小时概念 + 1 小时手写代码，配套课后选择题。
- 第 2 周：图、查找、排序，刷 3 套历年真题，错题按考点归类，周末全真模拟一次。
- 考前 3 天：只看错题本与哈夫曼/AVL/快排三个高频手写题，不再学新内容。
